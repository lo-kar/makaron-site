## 2. How deployment works

A systemd timer on the server runs `server/sync.sh` every 2 minutes. It does `git fetch` + `git reset --hard origin/main`,
rebuilds the Caddyfile from `server/domains.txt`, and reloads Caddy. **Pushing to `main` is the deployment** — nothing else to do.
There is no SSH access needed for day-to-day work; the owner holds the server keys.

Caddy config (generated by `sync.sh`): serves `site/` as the web root, `try_files {path} /index.html`, long cache headers on `assets/`,
automatic HTTPS via Let's Encrypt.

### Going live on makaron.com
1. DNS: `A` record for `makaron.com` → `135.181.95.147`; `A` (or CNAME to apex) for `www`.
2. In the repo, replace `auto` in `server/domains.txt` with two lines: `makaron.com` and `www.makaron.com`. Push.
3. Within 2 minutes Caddy picks up the hostnames and obtains certificates. Keep `auto` in the file too if you want the sslip.io URL to keep working.

### JS modules (all in the single script, top to bottom)
- **Loader** — intro, `.Loader.is-done` slides it away.
- **Router** — `route()` on `hashchange`/load; also calls `wakeVideos()`.
- **Lenis** — smooth scroll; pinned sections use `height:100svh;height:100dvh`.
- **Story canvas** (`#home`) — stills hard-cut on scroll progress; text layers with show windows; an SVG S-curve connector (`placeConnector()`) between the "tin" word and the statement, measured from layout boxes and flipped when the target is left of the source. The statement is kept measurable while hidden (`display:block; visibility:hidden`).
- **Nav theme** — `setNavTheme('dark'|'light')` as sections scroll under the header; also updates `<meta name="theme-color">` and `html` background so iOS Safari bars match.
- **Videos** — IntersectionObserver plays/pauses; `wakeVideos()` nudges autoplay on route change and on first touch/click/key (iOS low-power mode).
- **Journal filters** — see above.
- **Contact form** — **front-end only.** Validates the email, shows a thank-you line, resets. Nothing is sent anywhere. Wire it to a backend / form service before launch (see §5).
- **Consent** — bottom sheet, key `localStorage['mk-consent-v1']` with `{analytics, marketing}`. Any `<script type="text/plain" data-consent="analytics|marketing">` is activated only after consent — drop analytics/pixel tags in that form. "Cookie settings" link in the footer reopens the sheet.

## 5. Open items before launch

1. **Checkout.** "Order now" → `#contact`. Decide: Shopify Buy Button / Stripe Payment Links / Snipcart, or a proper store. Prices: 500 ml £24.99 · 2.5 L £89.99 · 18 × 500 ml £359.99 · gift set £119.99. Olive oil is zero-rated for UK VAT.
2. **Contact form backend.** Currently no submission. Options: Formspree/Basin, a Cloudflare Worker, or a small endpoint on the same server (Caddy can reverse-proxy). The form promises "your 10% code is on its way" — that needs an email flow (or change the copy).
3. **Placeholders in legal pages**: Terms show `[GB 000 0000 00]` for the VAT number; check `[two years]` / `[90 days]` style placeholders in Terms/Privacy.
4. **Domain**: see §2.
5. **Analytics**: none installed. Add via the consent-gated `<script type="text/plain" data-consent="analytics">` pattern.
6. **SEO**: single `<title>Makaron</title>` and one meta description for all routes. If per-route titles matter, set `document.title` in `route()`; for crawlable URLs the hash routes would need to become real paths (Caddy already falls back to `index.html`, so `/journal` etc. can be served without server changes).
7. **Video weight**: 33 MB of MP4 on first load paths. Consider WebM/AV1 variants or lazy `preload="none"` on below-the-fold videos.
